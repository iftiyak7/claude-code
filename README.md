# Jashore360 — যশোরের সবকিছু, এক অ্যাপে

যশোরের জরুরি সেবা, হাসপাতাল, রেস্টুরেন্ট, দোকান, সার্ভিস, হোটেল, শিক্ষা ও দর্শনীয় স্থানের যাচাইকৃত তথ্য।
মোবাইল-ফার্স্ট ওয়েব অ্যাপ (PWA) + Android APK + ল্যান্ডিং পেজ + পূর্ণ অ্যাডমিন প্যানেল, বাংলা ও English, লাইট ও ডার্ক থিম। সার্ভার শুধু Python-এর স্ট্যান্ডার্ড লাইব্রেরি ও SQLite ব্যবহার করে — কোনো প্যাকেজ ইনস্টল লাগে না।

## VPS-এ ইনস্টল / আপডেট (এক কমান্ড)

Hostinger → VPS → **Web console**-এ:

```bash
curl -fsSL https://raw.githubusercontent.com/iftiyak7/claude-code/claude/vigilant-heisenberg-wpt1tp/deploy/install.sh | bash
```

- অ্যাপ সার্ভিস হিসেবে চলে (`systemctl status jashore360`), রিস্টার্টে নিজে চালু হয়।
- CloudPanel থাকলে `jashore360` নামের সাইটটিকে (যেমন jashore360.cloud) অ্যাপের সাথে যুক্ত করে ও SSL বসায়।
- প্রথমবার অ্যাডমিন ইউজারনেম/পাসওয়ার্ড দেখায় (`/root/jashore360-admin.txt`-এও থাকে)।
- আপডেট করতে একই কমান্ড আবার চালান। ডেটাবেস ও ছবি `/var/lib/jashore360`-এ থাকে, আপডেটে মুছে না।

- `https://আপনার-ডোমেইন` — ল্যান্ডিং পেজ (অ্যাপে কী আছে + APK ডাউনলোড)
- `https://আপনার-ডোমেইন/app/` — অ্যাপ
- `https://আপনার-ডোমেইন/admin` — অ্যাডমিন প্যানেল
- `https://আপনার-ডোমেইন/download/jashore360.apk` — সর্বশেষ Android অ্যাপ

পাসওয়ার্ড ভুলে গেলে:
```bash
sudo -u j360svc python3 /opt/jashore360/server/server.py --data /var/lib/jashore360 reset-password admin
```

## লোকাল ডেভেলপমেন্ট

```bash
python3 server/server.py --data ./data            # http://127.0.0.1:8360
python3 server/server.py --data ./data ensure-admin   # প্রথম অ্যাডমিন বানায়, পাসওয়ার্ড দেখায়
```

## Android অ্যাপ (APK)

`android/` এ ছোট (~৫০ KB) WebView অ্যাপ, যা `/app/` খোলে। ইনস্টলার VPS-এ এতে আপনার ডোমেইন বসায় এবং
`/root/jashore360-signing` এ তৈরি কী দিয়ে সাইন করে — **এই ফোল্ডারের ব্যাকআপ রাখুন**; কী হারালে পুরোনো অ্যাপের উপর আপডেট বসবে না।

নতুন ভার্সন: `android/AndroidManifest.xml`-এ `versionCode` বাড়িয়ে `android/build.sh` চালান, commit করুন, তারপর ইনস্টল কমান্ড আবার চালান।
অ্যাপের ভেতরে পুরোনো ভার্সন থাকলে ব্যবহারকারী "নতুন ভার্সন এসেছে" দেখবেন।

## লঞ্চের আগে

1. জাতীয় হটলাইনগুলো (৯৯৯, ১৬১৬৩, ১৬২৬৩, ১০৯, ১০৯৮, ১০৯০, ৩৩৩) আরেকবার যাচাই করুন।
2. স্থানীয় থানা/হাসপাতালের নম্বর ইচ্ছাকৃতভাবে ফাঁকা — মাঠপর্যায়ে যাচাই করে অ্যাডমিন থেকে যোগ করুন।
3. "নমুনা" চিহ্নিত রেস্টুরেন্ট/দোকান/হোটেল কাল্পনিক — আসল তথ্য যোগ করে অ্যাডমিন → সব তালিকা → ধরন: নমুনা → "সব নমুনা মুছুন"।

## কাঠামো

```
public/            ল্যান্ডিং (index.html, landing.*), অ্যাপ (app.html, app.js, app.css, i18n.js, sw.js) ও admin/
android/           Android WebView অ্যাপ (base.apk, build.sh)
server/sign_apk.py VPS-এ APK সাইন করে
server/server.py   HTTP সার্ভার + JSON API + SQLite
server/seed.json   প্রথম চালুতে ডেটাবেসে বসানো প্রাথমিক তথ্য
deploy/install.sh  VPS ইনস্টল/আপডেট স্ক্রিপ্ট
```

> Jashore360 একটি স্বতন্ত্র তথ্য প্ল্যাটফর্ম, সরকারি অ্যাপ নয়, এবং নিজে কোনো জরুরি সেবা দেয় না।
