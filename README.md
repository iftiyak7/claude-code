# Jashore360 — যশোরের সবকিছু এক অ্যাপে

যশোরের জরুরি সেবা, হাসপাতাল, রেস্টুরেন্ট, দোকান, লোকাল সার্ভিস, হোটেল, শিক্ষা ও দর্শনীয় স্থানের তথ্য এক জায়গায়।
এটি একটি **Progressive Web App (PWA)**: হালকা, দ্রুত, অফলাইনে চলে, আর Android/iPhone-এ "Add to Home screen" দিলে অ্যাপের মতো ইনস্টল হয়।

## চালানো

কোনো build বা dependency লাগে না।

```bash
python3 -m http.server 8080
# তারপর ব্রাউজারে http://localhost:8080
```

**অনলাইনে প্রকাশ:** GitHub → Settings → Pages → "Deploy from a branch" → branch ও `/ (root)` বেছে নিন। Netlify, Vercel বা Cloudflare Pages-এও ফোল্ডারটি সরাসরি আপলোড করা যায়।

## লঞ্চের আগে যা অবশ্যই করতে হবে

1. **তথ্য যাচাই:** `js/data.js`-এ জাতীয় হটলাইনগুলো (৯৯৯, ১৬১৬৩, ১৬২৬৩, ১০৯, ১০৯৮, ১০৯০, ৩৩৩) `verified` চিহ্নিত। লঞ্চের আগে এগুলো আরেকবার যাচাই করুন এবং `verifiedAt` তারিখ দিন। স্থানীয় থানা, হাসপাতাল ও স্থানের ফোন নম্বর ইচ্ছাকৃতভাবে ফাঁকা রাখা হয়েছে, কারণ অনুমানে নম্বর বসানো যাবে না। মাঠপর্যায়ে যাচাই করে যুক্ত করুন।
2. **নমুনা তথ্য সরান:** `demo: true` চিহ্নিত সব রেস্টুরেন্ট, দোকান, হোটেল ও সার্ভিস কাল্পনিক। আসল ব্যবসার তথ্য দিয়ে বদলাতে হবে।
3. **ব্যাকএন্ড:** এখন রিভিউ, জমা ও অ্যাডমিনের পরিবর্তন শুধু ওই ব্রাউজারেই (localStorage) থাকে। সবার মধ্যে শেয়ার করতে Supabase (PostgreSQL + Auth + Storage) যুক্ত করুন:
   - `listings`, `reviews`, `submissions`, `reports` টেবিল, আর `js/data.js`-এর ফিল্ডগুলোই কলাম হবে
   - ফোন OTP লগইন; অ্যাডমিনের জন্য Row Level Security ও role
   - অ্যাডমিন প্যানেলের "JSON এক্সপোর্ট" দিয়ে বর্তমান ডেটা ইমপোর্ট করা যাবে
4. **অ্যাডমিন সুরক্ষা:** `#/admin` এখন শুধু ডেমো, কোনো লগইন নেই। প্রোডাকশনে সার্ভার-সাইড অথেনটিকেশন লাগবে।

## ফাইল কাঠামো

```
index.html            অ্যাপ শেল ও বটম নেভিগেশন
css/app.css           ডিজাইন (লাইট/ডার্ক, মোবাইল-ফার্স্ট)
js/data.js            ক্যাটাগরি, এলাকা, রেটিং মানদণ্ড ও সিড তথ্য
js/app.js             রাউটার, পেজ, সার্চ, রিভিউ, অ্যাডমিন
sw.js                 অফলাইন ক্যাশ (stale-while-revalidate)
manifest.webmanifest  PWA ইনস্টল তথ্য
```

নতুন তথ্য যোগ করতে `js/data.js`-এর `items`-এ একটি অবজেক্ট যোগ করুন। ফাইলের উপরের মন্তব্যে সব ফিল্ডের ব্যাখ্যা আছে। ডেটা বা কোড বদলালে `sw.js`-এর `CACHE` ভার্সন বাড়ান (`j360-v2`…), তাহলে ব্যবহারকারীরা আপডেট পাবেন।

## পরবর্তী ধাপ (Phase 2)

রক্তদাতা নেটওয়ার্ক (সম্মতিভিত্তিক, নম্বর গোপন), চাকরি, বাসা ভাড়া, যাতায়াত, খবর ও ইভেন্ট, অফার ও কুপন, বিজনেস ড্যাশবোর্ড, ইন্টারঅ্যাকটিভ ম্যাপ। হোম ও এক্সপ্লোর পেজে এগুলোর "শীঘ্রই আসছে" জায়গা রাখা আছে।

> Jashore360 একটি স্বতন্ত্র তথ্য প্ল্যাটফর্ম, সরকারি অ্যাপ নয়, এবং নিজে কোনো জরুরি সেবা দেয় না।
