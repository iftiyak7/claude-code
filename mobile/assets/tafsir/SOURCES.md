# Tafsir — source

Tafsir Ibn Kathir in Bangla (Tawheed Publications translation), as published
on Quran.com / QUL (tafsir id 31), packaged via spa5k/tafsir_api. Built by
`scripts/build-tafsir.py`, which checks the ayah list of every surah against
the bundled mushaf and stores each passage once with the ayah range it covers.
Some Arabic quotations appear as "(আরবি)" in that digital edition.
