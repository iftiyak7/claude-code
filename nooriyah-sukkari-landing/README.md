# Nooriyah Sukkari Landing Page (WordPress Plugin)

nooriyah.com.bd এর জন্য **সুক্কারি মুফাত্তাল খেজুরের** হাই-কনভার্টিং, সুপার-ফাস্ট ল্যান্ডিং পেজ — মোশন গ্রাফিক্স সহ। সব কিছু WordPress ড্যাশবোর্ড থেকে এডিট করা যায়, কোনো কোড লাগবে না।

## ইনস্টল

1. `nooriyah-sukkari-landing.zip` ফাইলটি নিন (অথবা এই ফোল্ডারটি zip করুন)।
2. WordPress → **Plugins → Add New → Upload Plugin** → zip আপলোড → **Activate**।
3. অ্যাক্টিভেট করলেই `/sukkari-mufattal/` নামে একটি পেজ অটো তৈরি হবে।
4. ড্যাশবোর্ডের বাম মেনুতে **Sukkari Landing → সেটিংস** থেকে সব এডিট করুন।

অন্য কোনো পেজে ল্যান্ডিং দেখাতে: Page এডিট → **Template → “Sukkari Landing (Nooriyah)”**।
হোমপেজ বানাতে: **Settings → Reading → A static page → Homepage** এ পেজটি সিলেক্ট করুন।

## কী কী এডিট করা যায়

| টপ অফার বার | অফার লেখা, কাউন্টডাউন টাইমার (ঘণ্টা), স্টক লেখা |

| আসল বনাম সাধারণ | তুলনার টেবিল |

**লাইন ফিল্ড:** প্রতি লাইনে একটি আইটেম, কলাম আলাদা করুন ` | ` দিয়ে। যেমন প্যাকেজ:
```
ফ্যামিলি প্যাক | ১ কেজি | 1400 | 1650 | সবচেয়ে জনপ্রিয় | 123
```
(শেষের `123` হলো ঐচ্ছিক WooCommerce প্রোডাক্ট ID।)

**সেকশন সাজানো/লুকানো:** “সেকশনের ক্রম” এ লাইনগুলো উপরে-নিচে সরান, বা মুছে দিন।

## ব্র্যান্ড কালার (লোগো থেকে)

1. **সাধারণ ও ব্র্যান্ড** ট্যাবে Nooriyah এর লোগো আপলোড করুন (স্বচ্ছ PNG/SVG→PNG হলে সবচেয়ে ভালো)।
2. **রং** ট্যাবে **“লোগো থেকে ব্র্যান্ড কালার নিন”** চাপুন।
3. লোগোর মূল রংগুলো খুঁজে বের করে পেজের ৫টি রং অটো বসে যাবে — হালকা ব্র্যান্ড রং হবে হাইলাইট/গোল্ডেন লেখা, গাঢ় ব্র্যান্ড রং হবে বাটন ও ডার্ক সেকশন। বাটনের সাদা লেখা যেন পড়া যায়, সেভাবে রং অ্যাডজাস্ট হয়।
4. **সেভ করুন**। চাইলে পরে যেকোনো রং হাতে ঠিক করে নিতে পারবেন।

## অর্ডার

- অর্ডারগুলো **Sukkari Landing → অর্ডারসমূহ** এ জমা হয় (নাম, ফোন, ঠিকানা, প্যাকেজ, মোট) — স্ট্যাটাস বদলানো যায় (নতুন/কনফার্মড/পাঠানো/ডেলিভারড/বাতিল)।
- প্রতিটি অর্ডারে অ্যাডমিনকে ইমেইল যায়।
- WooCommerce চালু থাকলে প্রতিটি অর্ডার **WooCommerce → Orders** এ-ও “Processing” স্ট্যাটাসে, Cash on Delivery হিসেবে তৈরি হয় — প্রোডাক্ট ID ছাড়াই। প্যাকেজে WooCommerce প্রোডাক্ট ID দিলে অর্ডারটি সেই প্রোডাক্টের সাথে লিংক হয় ও স্টক কমে।
- আগের অর্ডারগুলো WooCommerce এ পাঠাতে: অর্ডারসমূহ লিস্টে অর্ডার সিলেক্ট করে **Bulk actions → “WooCommerce এ পাঠান”** → Apply। আগে পাঠানো অর্ডার আবার পাঠানো হয় না।
- দাম সবসময় সার্ভারে হিসাব হয় — ব্রাউজার থেকে দাম পাল্টানো যায় না।
- স্প্যাম সুরক্ষা: হানিপট, টাইমিং চেক, প্রতি IP ১০ মিনিটে সর্বোচ্চ ৫টি অর্ডার।
- ফোন নম্বর বাংলা বা ইংরেজি সংখ্যায় লেখা যায়, +880 সহ বা ছাড়া।
- Facebook Pixel দিলে `ViewContent`, `InitiateCheckout`, `Purchase` (মূল্য সহ) অটো ট্র্যাক হয়।

## কেন সুপার-ফাস্ট

- থিমের CSS/JS ও অন্য প্লাগিনের স্ক্রিপ্ট লোড হয় না (দরকার হলে সেটিংস থেকে চালু করা যায়)।
- jQuery বা কোনো লাইব্রেরি নেই; CSS ইনলাইন, একটি ছোট JS ফাইল `defer` এ।
- সব মোশন গ্রাফিক্স CSS/SVG দিয়ে — কোনো ভারী ভিডিও/GIF/Lottie নেই।
- ছবি lazy-load ও responsive (srcset); হিরো ছবি প্রি-লোড হয়।
- ফন্ট non-blocking ভাবে লোড হয়; চাইলে বন্ধ করা যায়।
- যে ভিজিটর “Reduce motion” চালু রেখেছেন, তাঁদের জন্য অ্যানিমেশন বন্ধ থাকে।
- পেজ ক্যাশ (LiteSpeed, WP Rocket ইত্যাদি) এর সাথে কাজ করে — অর্ডার ফর্ম nonce-নির্ভর নয়।

## মোশন গ্রাফিক্স

ভাসমান খেজুর পার্টিকেল, গোল্ডেন শিমার হেডলাইন, ভাসমান হিরো ছবি ও ঘূর্ণায়মান রিং, পালস + শাইন CTA বাটন, চলমান ট্রাস্ট স্ট্রিপ, কাউন্ট-আপ কাউন্টার, স্ক্রল-রিভিল, লাইভ কাউন্টডাউন, স্টক বার, অর্ডার সামারি বাম্প, সফল অর্ডারের চেকমার্ক ড্র অ্যানিমেশন, স্টিকি মোবাইল অর্ডার বার।

## টিপস (কনভার্সনের জন্য)

- হিরোতে স্বচ্ছ ব্যাকগ্রাউন্ডের (PNG/WebP) আসল প্রোডাক্ট ছবি দিন, ৮০০×৮০০ পিক্সেলের মতো।
- ছবি আপলোডের আগে WebP তে কনভার্ট করুন (২০০KB এর নিচে রাখুন)।
- রিভিউ সেকশনে আসল গ্রাহকদের রিভিউ ও মেসেঞ্জার স্ক্রিনশট দিন — ডেমো রিভিউগুলো বদলে দিন।
- ডেমো দাম ও ফোন নম্বর আপনার আসল দাম ও নম্বর দিয়ে বদলে নিন।
